===============================================================
  Pixel RPG UI MegaPack
  by IndigoLay
===============================================================

A complete pixel-art RPG UI collection bundling four individual
asset packs into one package. Everything you need to build
beautiful retro-style game interfaces.


---------------------------------------------------------------
  INCLUDED PACKS
---------------------------------------------------------------

  01. Magic Book UI (v1.1)
      Animated magic book with 150+ RPG item icons,
      bookmarks, elemental badges, and navigation buttons.

  02. Pixel Adventure Book UI: Fantasy RPG Kit
      Book-style RPG UI kit with 183 sprites, 9 prefabs,
      tab switching system, and letter UI bonus set.

  03. Pixel UI HUD: Fantasy RPG Kit
      HUD/UI asset pack with status bars (9 color variations),
      18 icons, panels, slots, and 2 ready-to-use prefabs.

  04. Pixel Skill Icons & Book UI
      2,168+ pixel skill icons (4 classes, 4 sizes, normal &
      disabled states) with book-style skill detail UI and
      level up popups.


---------------------------------------------------------------
  REQUIREMENTS
---------------------------------------------------------------

  - Unity 6 (6000.x) or later
  - TextMeshPro (included with Unity)
  - Input System package (com.unity.inputsystem)
    * Required by Pixel Skill Icons & Book UI (04)
  - Universal Render Pipeline (URP) recommended


---------------------------------------------------------------
  HOW TO IMPORT
---------------------------------------------------------------

  1. Open your Unity project.
  2. Import the package via Assets > Import Package > Custom Package.
  3. A dialog will appear asking you to import TMP Essential
     Resources if not yet installed. Click "Import TMP Essentials".
  4. Ensure the Input System package is installed via
     Window > Package Manager if you plan to use the Skill Book UI.
