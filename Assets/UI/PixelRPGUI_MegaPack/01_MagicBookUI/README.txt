========================================
  Magic Book UI
  Version 1.1
========================================

Thank you for purchasing Magic Book UI!

A pixel-art style magic book UI kit with animated book opening/page flipping,
150+ RPG item icons, decorative bookmarks, elemental badges, and navigation buttons.
Perfect for inventory, bestiary, quest logs, and lore books in your fantasy game.

----------------------------------------
  How to Use
----------------------------------------

1. Import the package into your Unity project.
2. Open the demo scene at "MagicBookUI/Demo/Demo_Scene" to preview.
3. Use the prefabs, sprites, and animations in your own UI setup.
4. Fonts use TextMeshPro - ensure TMP Essentials are imported.


----------------------------------------
  Requirements
----------------------------------------

- Unity 2020.3 LTS or later
- TextMeshPro (for SDF font assets)
